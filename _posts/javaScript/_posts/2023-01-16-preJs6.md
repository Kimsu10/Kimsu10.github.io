# 2. 생소한 수학 표현식

## 1. ++/--

`++`는 변수의 값에 1을 간단하게 더할 수 있게 해준다. 반대로 `--` 는 변수에서 1을 !ㅐ준다.  
![](https://velog.velcdn.com/images/kimsu10/post/4bedafe8-a1f0-40b0-8508-2ea24c569d96/image.png)

참고로 const를 사용하면 값을 재할당을 할수 없어 에러가 뜬다.

![](https://velog.velcdn.com/images/kimsu10/post/1dd65f5a-a6fc-4e27-b828-a0b05417e30e/image.png)

증감연산자를 사용하는경우 `++`/`--`의 위치에따라 다르게 사용하기때문에 주의해야한다.
++를 하면 1이 붙어서 나올것같지만 실제로는 다른값이 나올수 있다.

## 1) number++

> ### 아래의 코드는 어떤 값이 나올까?

```js
let a = 1;
let aPlus = a++;
```

나는 1과 2가 나올줄 알았는데, 답은 2와 1이였다.

![](https://velog.velcdn.com/images/kimsu10/post/3b62a5c4-d4b2-46ff-9cc2-056bca131eaf/image.png)

이렇게 나온 이유는 대개 코드는 위에서부터 스캔하기도하지만 동시에 왼쪽에서 오른쪽으로 스캔하기도해서이다.
`let aPlus = a`를 **먼저 처리**하고 그 뒤에 `++`를 하기때문에 aPlus에 a가 먼저 할당되어버리고 `++`가 적용이 되지 않기때문이다.

**`num++`를 사용할경우 선언된 변수를 사용하고 1씩 증가시키고 싶을때 사용하면 된다.**

## 2) ++number

**`++num`은 변수를 1증가 시킨뒤 사용하고 싶을때 쓰면된다.**
아래의 코드처럼 `++`를 앞에 적으면 같은 값이 나온다.
![](https://velog.velcdn.com/images/kimsu10/post/02234a03-34c6-439d-ad20-7d3cbb661a02/image.png)
위의 코드를 풀어쓰면 아래와 같다.

```js
let a = 1;
a++;
let aPlus = a;
```
