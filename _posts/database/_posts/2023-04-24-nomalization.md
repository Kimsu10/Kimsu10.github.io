# 1.정규화(Nomalization)란?

- 중복된 데이터를 분리하는것

# 2. Normal Form 정규형의 종류

- 행(row):
- 열(collumn, 기둥):

| 종류 |                               설명                               |
| :--: | :--------------------------------------------------------------: |
| 1NF  | 하나의 필드에는 하나의 속성만 들어가야한다 (다가속성X,복합속성X) |
| 2NF  |                                                                  |
| 3NF  |                                                                  |

실무는 3정규화정도까지만 알아도된다. 그외에는 DBA분들이 있다고한다.

## 1NF(1정규형)

- 다가속성이 있으면 안된다.(1열에 2개 이상 정보가 존재)
- 복합속성이 있으면 안된다.(똑같은 정보가2행이상 존재)
- 중복속성이 있으면 안된다. => 테이블을 나눠주자

이렇게 나누다보면 중복되지 않는 키가 발생하는데 Primary KEY라고한다.

코드를 묶어서 하나의 PK로 지정하는것을 복합키라고 한다.

테이블내에 관련이 없는 정보들이 연결된 경우, 테이블을 분리하는것이 2NF와 3NF의 목적이다.
(ex 유저정보와 유저의 상품목록이 함께있는경우)

## 2NF (2정규형)

- 저장에는 효율적이나 읽기는 느리다.  
  (조회에 최적화된 테이블은 나중에 따로 만들면 된다.)

## 3NF(3정규형)

- 서로 관련없는 테이블을 나누자
