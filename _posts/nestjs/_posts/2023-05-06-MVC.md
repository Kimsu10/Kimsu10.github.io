# 1. MVC(Model View Controller)?

과거 브라우저와 개발자만이 존재했을당시에 하나의 개발서버에서json 통신과 html로 통신을 다하였디.

M(models) database 관련 부분  
V(views) 화면에 보여지는 부분으로 HTML 코드  
C(Controllers) API 부분
