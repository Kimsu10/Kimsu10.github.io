### 1-3. 배열의 최대값과 최소값 구하기

```java
import java.util.Arrays;

int [] arr ={1,2,3,4,5};

int max = Arrays.stream(arr).max().getAsInt();
int min = Arrays.stream(arr).min().getAsInt();

System.out.println(max); // 5
System.out.println(min); // 1
```

```js
let arr = [1,2,3,4,5];

let max = arr[0];
let min = arr[0];

for(let i = 1; i < arr.length; i++){
    if(max < arr[i]){
        max = arr[i];
    }
    if(min > arr[i]){
        min = arr.[i];
    }
}

console.log(max); // 5
console.log(min); // 1
```

## 4-2. 버블 정렬하기

- 앞의 요소와 뒤의 요소의 값을 비교하고 정렬하는 방법
- 시간 복잡도가 O(n)

```java

```

```js
let tmp = 0;

for (let i = 0; i < arr.length; i++) {
  for (let j = i + 1; j < arr.length; j++) {
    if (arr[i] > arr[j]) {
      tmp = arr[i];
      arr[i] = arr[j];
      arr[j] = tmp;
    }
  }
}

console.log(arr);
```
