# 1. 두수의 합

> **문제 설명**
> 정수 num1과 num2가 주어질 때, num1과 num2의 합을 return하도록 soltuion 함수를 완성해주세요.
>
> **입출력예**
>
> | num1 | num2 | result |
> | :--: | :--: | :----: |
> |  2   |  3   |   5    |
> | 100  |  2   |  102   |

## 🔑 나의 답안 및 풀이

```js
function solution(num1, num2) {
  return num1 + num2;
}
```

예시에서 2+3=5, 100+2=102 이므로 num1+num2의 값을 return

# 2. 두수의 차

> **문제 설명**
> 정수 num1과 num2가 주어질 때, num1에서 num2를 뺀 값을 return하도록 soltuion 함수를 완성해주세요.
>
> **입출력 예**
>
> | num1 | num2 | result |
> | :--: | :--: | :----: |
> |  2   |  3   |   -1   |
> | 100  |  2   |   98   |

## 🔑 나의 답안 및 풀이

```js
function solution(num1, num2) {
  return (answer = num1 - num2);
}
```

예시에서 num1 -num2를 결과값으로 나오게하였으므로 num1- num2를 return.

# 3. 두수의 곱

> **문제 설명**
> 정수 num1, num2가 매개변수 주어집니다. num1과 num2를 곱한 값을 return 하도록 solution 함수를 완성해주세요.
>
> **입출력 예**
>
> | num1 | num2 | result |
> | :--: | :--: | :----: |
> |  3   |  4   |   12   |
> |  27  |  19  |  513   |

## 🔑 나의 답안 및 풀이

```js
function solution(num1, num2) {
  return (answer = num1 * num2);
}
```

num1 ㅁ num2 의 결과값이 12가 되므로 ㅁ에는 `*`가 들어가야한다. 그리고 그값을 return.

# 4. 몫 구하기

> **문제 설명**
> 정수 num1, num2가 매개변수로 주어질 때, num1을 num2로 나눈 몫을 return 하도록 solution 함수를 완성해주세요.
>
> **입출력 예**
>
> | num1 | num2 | result |
> | :--: | :--: | :----: |
> |  10  |  5   |   2    |
> |  7   |  2   |   3    |

## 🔑 나의 답안 및 풀이

```js
function solution(num1, num2) {
  return Math.floor(num1 / num2);
}
```

예시에서 num1을 num2로 나누었을때의 몫이 정수로 나온다. 10/5는 2로 깔끔하게 떨어지지만, 7/2는 3.5이므로 `Math.floor`를 사용하여 소수점을 내렸다.
