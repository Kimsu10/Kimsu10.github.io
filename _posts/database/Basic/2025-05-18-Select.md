SQLD 시험 대비 공부 정리
{: .notice--info}

# 1. \* (Asterisk )

- SELECT시 `*`는 **모든 열**을 선택하는 키워드
- 원하는 열을 `,` 로 나열해서 조회할 수 있다

- **ALL**

  - \*과 같이 모든 열을 조회한다

  ```sql
  SELECT ALL  열1, 열2, 열3, FROM  테이블명
  ```

- **DISTINCT**

  - ALL 과 달리 <u>중복을 제외하고 조회</u>한다
  - 나열된 모든 열의 중복된 값을 제외하고 가져온다

  ```sql
    SELECT DISTINICT 열3, 열4 FROM  테이블명
  ```

# 2. AS (ALIAS)

- AS는 <u>컬럼명이나 테이블명에 별칭(alias) 을 줄 때</u> 사용한다
- <u>생략 가능</u>하나, 가독성을 위해 자주 명시적으로 사용함

  ```sql
  SELECT empno AS 사원번호,
  ename AS 사원이름,
  deptno AS 부서번호,
  job AS 직책
  FROM emp
  ```

- **" "(따옴표) 사용**
- 별칭에 <u>공백</u>이나 <u>특수기호(-, , %, 등)</u> 사용시
- SQL은 대소문자를 구분하지 않음! ➔ <u>소문자/대문자 구분</u>시

  ```sql
    SELECT empno AS "사원 번호",
    ename AS "이름1",
    deptno AS "부서-번호",
    job AS "Job"
    FROM emp
  ```

# 3. 산술 연산자(arithmetic operator)

- 산술연산자는 칼럼과칼럼, 칼럼과 숫자, 숫자와 숫자 모두 적용 가능하다

  ```sql
  SELECT empno,
       sal,                     -- 칼럼 급여
       sal + 500 AS 보너스포함급여,   -- 칼럼 + 숫자
       sal * 12 AS 연봉,           -- 칼럼 * 숫자
       sal + comm AS 총수입        -- 칼럼 + 칼럼
  FROM emp;
  ```

  > ⭐️ **산술 연산자와 NULL**
  >
  > - <u>어떤 산술연산이든 NULL과 만난다면</u> **NULL을 반환**한다

  ```sql
  SELECT empno,
        sal,
        comm,
        sal + comm AS 총수입_NULL_포함
  FROM emp;
  ```

# 4. 합성 연산자 (Concatenation Operator)

- 문자열을 결합하는데 사용한다

- **Oracle**

  - 문자열 결합에 `||` 사용

  ```sql
  SELECT ename || '의 직책은 ' || job || '이고 연봉은 '|| sal || '이다'
  ```

- **SQL Server**

  - 문자열 결합에 `+` 사용
  - 📌 SQL Server에서는 <u>숫자를 문자열로 형 변환(CAST) 해야</u> 결합이 가능

  ```sql
  SELECT ename + '의 직책은 ' + job + '이고 연봉은 '
      + CAST(sal AS VARCHAR) + '이다' AS 설명
  FROM emp;
  ```

- 공통 함수: **CONCAT()**

  - CONCAT(str1, str2) 함수는 <u>두 문자열만 결합</u> 할 수 있다

  ```sql
  SELECT CONCAT(CONCAT(ename, '의 직책은 '), job) AS 설명
  FROM emp;
  ```
