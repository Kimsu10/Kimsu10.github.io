# \* (asterisk )

- SQL에서 SELECT \*는 "모든 열"을 선택하는 키워드

- 조회하는 열을 , 로 나열해서 가져올 수도 있다

  ```sql
  SELECT ALL  열1, 열2, 열3, FROM  테이블명
  ```

- DISTINCT 를 사용하면 ALL 과 달리 중복을 제외하고 가져올 수 있다
- 나열된 모든열의 중복된 값을 제외하고 가져온다

  ```sql
  SELECT DISTINICT 열3, 열4 FROM  테이블명
  ```

# 2. AS (ALIAS)

- AS를 사용해서 컬럼이나 테이블에 별명을 줄 수 있다

  ```sql
  SELECT empno AS 사원번호,
  ename AS 사원이름,
  deptno AS 부서번호,
  job AS 직책
  FROM emp
  ```

- 특수기호를 사용하면 에러가 나므로 "" 로 감싸고 사용해야한다
- 내부적으로 대소문자를 구분하지 않으므로 "" 로 감싸서 사용하면 구분된다

```sql
  SELECT empno AS "사원 번호",
  ename AS "이름1",
  deptno AS "부서-번호",
  job AS "Job"
  FROM emp
```
