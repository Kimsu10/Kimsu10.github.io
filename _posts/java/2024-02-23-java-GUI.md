# GUI (Graphical User Interface)

- 사용자가 마우스, 키보드 등을 통해 시각적으로 프로그램과 상호작용할 수 있게 만들어주는 인터페이스

## JAVA GUI의 특징

- 자바 GUI 프로그램은 **콘솔 대신 창(window)**에서 작동한다
- 마우스 클릭, 텍스트 입력, 버튼 클릭, 화면 전환 등을 직접 구현할 수 있다
- 기본적으로는 자바의 AWT, Swing, JavaFX 같은 GUI 라이브러리를 사용한다

## Java GUI 종류

### 1. AWT(Abstract Windows Toolkit)

- 자바 초창기 GUI 툴킷. OS의 GUI 자원을 사용 → 무겁다
- 운영체제가 제공하는 자원을 이용하여 컴포넌트 생성한다
- 따라서 운영체제 별로 느낌이 다르다
  - `java.awt.\*`
  - Button, Frame, TextField

### 2. Swing

- AWT를 기반이나 더 가볍고 다양한 컴포넌트 제공
- 컴포넌트가 자바 코드로 직접 구성되기 때문에 운영체제와 무관하게 일관된 UI 제공
- 패스워드 필드, 포맷 텍스트 필드 등 고급 컴포넌트 포함
- `javax.swing.\*`

### Java 2D API

- Swing과 함께 사용할 수 있는 그래픽 처리 API
- 그림, 이미지, 애니메이션 기능을 제공
- GUI에 직접 그래픽을 추가하고 싶을 때 사용

### 데이터 전송

- 사용자의 입력과 UI 간의 데이터 이동을 지원
- 자르기, 복사, 붙이기 , Drag and Drop 등 데이터 전송 기능 제공
- 드래그 앤 드롭(Drag and Drop) + Undo / Redo 기능 구현 가능

### Container

- 사용자가 보는 창(Window)의 기본 뼈대
- 자바 GUI에서 컴포넌트들을 올려놓는 기본 UI 구조 틀
- 여러 개의 컴포넌트(버튼, 텍스트필드 등)를 포함
- Container는 실제로는 Component보다 작은 개념
  - (예) Frame, Window, Panel, Dialog, Applet
  - (예) JFrame, JDialog, JApplet, JPanel, JScrollPane

| 구분          | 예시 컴포넌트            |
| ------------- | ------------------------ |
| 상위 컨테이너 | JFrame, JDialog, JApplet |
| 하위 컨테이너 | JPanel, JScrollPane 등   |

Container는 실제로는 Component보다 작은 개념 (Container는 Component를 상속)

## Frame 생성 하기

### 방법1 : JFrame 객체 생성

```java
import javax.swing.\*;

public class FrameTest1 {

    public static void main(String[] args) {
        // TODO Auto-generated method stub
        JFrame f = new JFrame("Frame Test");
        f.setSize(300,200); //크기 지정
        f.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE); //swing에만 존재한다. x버튼 클릭시 종료
        f.setVisible(true); // Container보이기
    }

}
```

### LayoutManager

- Container 위에 Component들을 올릴 때 자리 배치 방법
- 예: FlowLayout, BorderLayout , GridLayout , CardLayout , GridBackLayout ...

- Layout 설정 형식
  ```java
  Container.setLayout(new 레이아웃종류());
  ```

### Flow Laytout

<p align="center">
<img src="/assets/images/Java/3-3.gif"/>
</p>

- 기본적으로 component들이 왼쪽에서 오른쪽으로 추가되는 형태
- Container의 크기가 변하면 component의 크기는 그대로 이며, 위치가 변경된다. (디폴트: 가운데 정렬)
- 예: Panel, Applet

```java
import java.awt.FlowLayout;

class FrameTest extends JFrame{

    public FrameTest() {
        JButton button  = new JButton("버튼");
        this.add(button);
        setSize(300,200);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setTitle("Practice Frame");
        // FlowLayout설정
        setLayout(new FlowLayout());
        setVisible(true);
    }
}
```

### Border Laytout

<p align="center">
<img src="/assets/images/Java/3-4.gif" />
</p>

- 기본적으로 컴포넌트들이 틀 형태로 존재

- Border Layout에 component를 추가할 때는 `this.add(컴포넌트, 위치);` 를 지정해야한다.

```java
class FrameTest extends JFrame{

    public FrameTest() {

        JButton button  = new JButton("버튼");

        setSize(300,200);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setTitle("Practice Frame");
        setVisible(true);
    }

}
```

### Grid Layout

<p align="center">
  <img src="/assets/images/Java/3-5.png" width="400"/>
</p>

- 테이블 형태의 레이아웃이다. 인수를 주지 않으면 행은 1행으로 고정되고 열이 계속해서 추가된다
- 행/열 인수에 0이 들어갈 수 있다
- ex) (2,0)이면 행은 2행으로 고정, 열은 무한대

```java
import java.awt.BorderLayout;
import java.awt.FlowLayout;
import java.awt.GridLayout;
import java.awt.LayoutManager;
import javax.swing.\*;

class FrameTest extends JFrame{

    public FrameTest() {

        JButton[] b  = new JButton[6];
        setLayout(new GridLayout(3,2));
        for(int i=0;i<b.length;i++) {
            b[i] = new JButton("button"+i);
            this.add(b[i]);
        }

        setSize(300,300);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setTitle("Practice Frame");
        setVisible(true);
    }
}
```

### Card Layout

- 러 개의 화면(패널)을 하나의 공간에 겹쳐 놓고, 그중 하나만 보여주는 방식
- JPanel과 함께 사용해서 "화면 전환"을 구현할 때 자주 사용
- setLayout에는 null로 지정한 후 setBounds로 직접적인 좌표값을 지정할 수 있다

```java
setLayout(null);
setBounds(0,0,0,0);
```

### 이벤트 처리

<p align="center">
<img src="/assets/images/Java/3-6.gif"/>
</p>
- `이벤트(event)` : 마우스로 클릭하거나 키보드로 누르는 일련의 모든 작동
- `리스너(Listener)` : 사용자가 마우스를 클릭하거나 키보드를 누를 때까지 기다리는 것

```
버튼을 클릭 ➔ 이벤트 객체가 발생 ➔ 이벤트 처리(이벤트 리스너 객체)
```

즉, 버튼에 반응하려면 이벤트 처리를 해야한다.

### 액션 이벤트 actionPerformed()

- 이벤트를 발생시키는 Component(버튼)가 존재해야함
- 이벤트 발생 감지 방법 : Listener 인터페이스를 사용

  - 클래스에서 implements 시켜 method를 구현 방법

    ```java
    MyClass implements ActionListener{
        public void actionPerformed(ActionEvent e){
        //꼭 구현해야하는 메소드
        //Action 이벤트를 처리하는 코드가 여기에 들어간다.
        }
    }
    ```

    - new로 생성하여 Component마다 리스너를 붙이는 방법

    ```java
    button1.addActionListener(new ActionListener(){메소드 구현..});
    ```

    ```java
    //Action 이벤트를 처리하는 코드가 여기에 들어간다.
    }
    }
    ```

