# 1. 옷가게 할인 받기

> **문제 설명**
> 머쓱이네 옷가게는 10만 원 이상 사면 5%, 30만 원 이상 사면 10%, 50만 원 이상 사면 20%를 할인해줍니다.  
> 구매한 옷의 가격 price가 주어질 때, 지불해야 할 금액을 return 하도록 solution 함수를 완성해보세요.
>
> **제한사항**

- 10 ≤ price ≤ 1,000,000
- price는 10원 단위로(1의 자리가 0) 주어집니다.
- 소수점 이하를 버린 정수를 return합니다.
  > **입출력 예**
  >
  > |  price  | result  |
  > | :-----: | :-----: |
  > | 150,000 | 142,500 |
  > | 580,000 | 464,000 |

## 💭 나의 답안 및 풀이

```js
function solution(price) {
  if (price >= 500000) {
    return Math.floor(price * 0.8);
  } else if (price >= 300000) {
    return Math.floor(price * 0.9);
  } else if (price >= 100000) {
    return Math.floor(price * 0.95);
  } else {
    return price;
  }
}
```

가격이 조건문에 true 라면 바로 할인율을 뺀가격에 소수점을 버리고 리턴하게하였다.

테스트 13~16까지 통과가 되지않았는데 질문하기를보니 소수점을 없애야한다고 해서 소수점을 없앴다.

질문하기가 없었다면 어떻게 풀었어야했을지 감이 안온다.

## 📚 다른 사람 답안

```js
function solution(price) {
  if (price >= 500_000) {
    return (price * 0.8) << 0;
  } else if (price >= 300_000) {
    return (price * 0.9) << 0;
  } else if (price >= 100_000) {
    return (price * 0.95) << 0;
  } else {
    return price;
  }
}
```

`<<`(left shift)연산자를 사용해서 풀어보기도 했으나 제대로 이해하지 못해서 다른사람의 답안으로 가져왔다.

내가 본 블로그에서 `<< 0` 을 사용하면 정수로 반환하여 소수점이 없어진다고 써있었는데, 스터디에서 그게 아닐거라고 다들의아해 하며 단순히 그렇게 생각하면 안된다고 제대로 알아보라고해서 더 알아보았다.

`<< count` 는 비트를 왼쪽으로 count 위치만큼 이동한 다음 결과를 정수로 강제 변환하여 숫자를 자르거나 정수로 변환하는 데 자주 사용된다고 한다.

> 10이라는 정수가 있는데 이것을 2진수로 바꾸면 00001010이된다.  
> 여기서 10 << 2 를 쓰면 10을 2진수로 바꾼 비트값을 각각 왼쪽으로 두 칸씩 이동하라는 뜻이다.  
> 두칸씩 이동하면 00101000(40)이 된다.  
> 반대로 10 >> 2를 쓰면 00000010(2)이 된다. 이 경우 10이 사라져버리는데 그냥 버려진 값이다.  
> 이는 시프트 연산자에 소수점이라는 개념이 없어서 허용범위를 넘어 그냥 없는값이 되버린것이다.

저번 스터디때 >> 연산자를 보고 간단한거 같아서 써봤는데 가볍게 공부했는데도 어렵다..

추가로 500`_`000의 `_`는500,000의 `,`와 같다.

# 2. 아이스 아메리카노

> **문제 설명**
> 머쓱이는 추운 날에도 아이스 아메리카노만 마십니다. 아이스 아메리카노는 한잔에 5,500원입니다.  
> 머쓱이가 가지고 있는 돈 money가 매개변수로 주어질 때, 머쓱이가 최대로 마실 수 있는 아메리카노의 잔 수와 남는 돈을 순서대로 담은 배열을 return 하도록 solution 함수를 완성해보세요.
>
> **입출력 예**
>
> | money  | result |
> | :----: | :----: |
> | 5,500  |  1,0   |
> | 15,000 | 2,4000 |

## 💭 나의 답안 및 풀이

```js
function solution(money) {
  const a = 5500;
  let c = Math.floor(money / a);
  return [c, money - a * c];
}
```

가진돈에서 커피값으로 나눈값을 floor를 사용하여 몫만 가져오게하여 잔(cup)수를 설정하였다.  
결과값은 배열로[잔수(c), money - 커피값 * 잔수]를 반환하게 하였다.

# 3. 나이 출력

> **문제 설명**
> 머쓱이는 40살인 선생님이 몇 년도에 태어났는지 궁금해졌습니다.  
> 나이 age가 주어질 때, 2022년을 기준 출생 연도를 return 하는 solution 함수를 완성해주세요.
>
> **입출력 예**
>
> | age | result |
> | :-: | :----: |
> | 40  |  1983  |
> | 23  |  2000  |
>
> **제한사항**

## 💭 나의 답안 및 풀이

```js
function solution(age) {
  return 2022 - age + 1;
}
```

Date생성자를 써야하나 생각하다 일단 써보자했는데 답이 맞았다.  
진짜 이게 맞나 싶어서 다른 사람들 답안을 보니 다들 비슷한 감상평이다.  
현재 년도에서 나이를 빼고 1을 더한 이유는 제한사항에 태어난 년도에 0살이 아닌 1살이기 때문에 +1을 해주었다.

# 4. 배열 뒤집기

> **문제 설명**
> 정수가 들어 있는 배열 num_list가 매개변수로 주어집니다. num_list의 원소의 순서를 거꾸로 뒤집은 배열을 return하도록 solution 함수를 완성해주세요.
>
> **입출력 예**
>
> |    num_list     |     result      |
> | :-------------: | :-------------: |
> |   [1,2,3,4,5]   |   [5,4,3,2,1]   |
> |  [1,1,1,1,1,2]  |  [2,1,1,1,1,1]  |
> | [1,0,1,1,1,3,5] | [5,3,1,1,1,0,1] |
>
> **제한사항**
>
> - 1 ≤ num_list의 길이 ≤ 1,000
> - 0 ≤ num_list의 원소 ≤ 1,000

## 💭 나의 답안 및 풀이

```js
function solution(num_list) {
  return num_list.reverse();
}
```

reverse메소드를 사용하여 뒤집어주었다.
