과거의 HTML에서는 글꼴, 배경색, 레이아웃 같은 스타일이 지정 가능했다.
하지만 점차 콘텐츠의 내용과 스타일이 화려해지면서 코드가 복잡해졌고, 유지보수도 어려워졌다.

이를 해결하기위해 HTML은 본래의 역할인 문서가 어떤 구조로 이루어져있는지 나타니는 언어가 되고, 웹페이지의 디자인 기능은 **스타일 시트**를 사용하는것이 표준적인 방법이 되었다.
스타일 시트의 대표적인 예가 `CSS(Cascading Style Sheets)`이다

# 1. CSS

CSS를 사용하면 이미지의 위치 지정, 선 스타일, 여백 등을 효율적으로 지정할 수 있다.

## 적용 방법

### 1. HTML 파일안에 직접 기술

```html
<html>
  <body>
    <h1>html 내부에 직접 스타일을 적용</h1>
    <div
      style="width: 300px; padding: 20px; background-color: #fff; border: 1px solid #ccc;"
    >
      <p>위의 div는 직접 스타일을 적용</p>
    </div>
  </body>
</html>
```

### 2. CSS를 별도의 파일 분리

이 경우 HTML 파일이 CSS 파일을 참조하는 형태로 스타일을 적용한다.

##### 장점

- HTML 코드가 간결해지고 유지보수가 쉽다.
- 웹사이트의 기본 디자인을 통일할 수 있다.
- 사용자 디바이스의 화면 크기엥 맞게 전환하는 반응형 디자인도 적용가능하다.
