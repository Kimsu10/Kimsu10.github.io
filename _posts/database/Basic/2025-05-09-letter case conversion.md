# 대/소문자 변환하기기

> 사용이유
>
> - 저장된 데이터가 대문자인지 소문자인지 확실하지 않을때 정확하게 데이터를 검색할 수 있다

> ENAME
>
> - 일반적으로 컬럼 이름으로 사용되는 사용자 정의 명칭

# UPPER(ENAME)

- 대문자로 출력

# LOWER(ENAME)

- 소문자로 출력

# INTICAP(ENAME)

- 첫번째 문자만 대문자로 출력, 뒤의 문자들은 소문자로 출력
