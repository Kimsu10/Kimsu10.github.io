# CRA

처음 리엑트를 설치하면 리엑트는 기본적인 UI기능만을 제공한다.  
그래서 개발환경을 구축하기(패키지 설치, 유지보수 등)에 어려움이있는데,  
이런 문제를 돕기위해 리엑트는 프로젝트를 시작하는데 필요한 개발환경을 세팅해주는 툴체인(toolchain)을 제공한다.  
그게 CRA(Create-React-App)고 아래의 명령어만으로 리엑트의 개발환경을 구축할 수 있다.

```
Create-React-App 프로젝트이름
```

명령어를 입력하면 진행할것인지 물어보는데 y를 눌러 설치한다.

![](https://velog.velcdn.com/images/kimsu10/post/c7fad18d-2187-400a-aaa7-2a696f713928/image.png)

이떄 `프로젝트 명`에는 `대문자`나 `~`,`!`,`()`,`*`,`^`등의 특수문자를 포함하면 `에러`가 발생한다.  
프로젝트 명은 `소문자`나 `kebaa-case`를 `사용`하여야한다.

설치가 완료되면 터미널 아래에 happy Hacking이라는 문구가 뜬다.

이때 바로 `npm start`를 입력하면 Missing script라며 에러메세지가 뜬다.

![](https://velog.velcdn.com/images/kimsu10/post/dba5cd5e-8718-4872-88bc-af9802f8e5df/image.png)

이유는 내가있는 위치(pwd)에서 프로젝트이름의 폴더를 새로 생성했는데 그 경로로 들어가서 실행하지 않아서 파일들이 없기때문이다.

![](https://velog.velcdn.com/images/kimsu10/post/25c58ace-5c86-4cc7-95a6-72b3d3688ac0/image.png)

```
//현재 위치 확인
pwd

//
cd 프로젝트명
```

프로젝트 폴더로 이동후 다시 `npm start`를 입력해서 아래의 이미지처럼 뜨면 잘 실행되는 것이다.

![](https://velog.velcdn.com/images/kimsu10/post/4b196d68-20e7-4167-b5d4-95950e07fb7c/image.png)
