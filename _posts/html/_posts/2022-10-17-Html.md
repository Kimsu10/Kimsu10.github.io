# HTML(HyperText Markup Lagnguage)

HTML은 웹페이지를 기술하기 위한 언어이다.
웹페이지가 어떤 구조로 이루어져있는지 태그를 이용해 제목,단락, 표 등을 정의한다.  
또한 이미지, 텍스트, 비디오, 버튼 등 웹사이트에 보여줄 내용을 구성한다.
브라우저(safari, chrome, ie..)는 HTML파일을 통해 어떻게 화면에 그려내면 되는지 파악한 후에 웹 페이지를 생성한다.

# 2. HTML 파일

HTML은 `.html` 확장자가 붙은 텍스트 파일이다.  
텍스트편집기(Text Editor)같은 간단한 메모작성 앱을 열고, .html 확장자로 저장한 후에
해당파일을 브라우저(크롬)에 drag & drop 하면 브라우저에서 HTML로 작성한것을 확인 할 수 있다.

```html
<!DOCTYPE html>
<html lang="ko">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>문서 제목</title>
    <style>
      /* 내부 CSS */
    </style>
    <script>
      // 내부 JavaScript
    </script>
  </head>
  <body>
    <header>
      <h1>제목</h1>
    </header>
    <nav>
      <ul>
        <li><a href="#">홈</a></li>
        <li><a href="#">소개</a></li>
      </ul>
    </nav>
    <main>
      <section>
        <h2>섹션 제목</h2>
        <p>섹션 내용</p>
      </section>
    </main>
    <footer>
      <p>&copy; 푸터 내용</p>
    </footer>
  </body>
</html>
```

## 3-1. tag(태그), content(내용)

HTML에서는 `<>`로 감싼 태그 기호를 사용해서 웹페이지에 표시할 텍스트나 이미지, 링크 등을 기술 할 수 있다.
브라우저는 태크 안의 내용을 읽고 '아, 이것은 텍스트구나, 저것은 이미지구나'하고 알 수 있다.  
 태그는 `<>` 로 감싸져 있다.

브라우저에서 태그(tag)(<태그이름>과 </태그이름>)은 보여주지 않는다.
즉, 내용(content) 부분만 보여준다.
내용의 왼쪽에 있는 것이 시작 태그(opening tag)이고, 내용 우측에 있는 것이 종료 태그(closing tag)이다.
종료태그 괄호를 닫기전에 /(slash)가 있다는 것을 꼭 기억하자.
대부분의 태그는 시작하면 꼭 끝맺음을 해야한다. 즉, 시작태그가 있으면 끝 태그도 꼭 있어야한다는 의미이다.

## 3-2. attribute(속성)

속성은 시작 태그에 위치하며 한 태그에 여러 속성을 지정할 수 있다.
div, a, img는 태그이고 class, href, src, alt는 속성이다.
