# 리눅스 디렉토리

> Directory : 파일 저장소

- 리눅스 디렉토리는 최상위 디렉토리(/)를 기준으로 하위 디렉토리들이 존재하는 계층적인 트리 구조로 되어있다.
- 디렉토리는 상위(부모) 디렉토리와 하위(자식) 디렉토리로 구분된다.

## 2. 종류 및 설명

| 디렉토리      | 설명                                                                                                                                                             |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/`           | 루트 디렉토리, 모든 파일 **시스템의 최상위 디렉토리**                                                                                                            |
| `/boot`       | 부트 디렉토리, 부팅시 커널 이미지와 부팅정보 파일을 저장                                                                                                         |
| `proc`        | 시스템 정보 디렉토리, 커널 기능을 제어                                                                                                                           |
| `/bin`        | 기본 명령어(사용자 및 시스템 명령어)가 저장된 디렉토리                                                                                                           |
| `/sbin`       | 시스템 **관리자 전용 명령어**가 저장된 디렉토리                                                                                                                  |
| `/etc`        | 시스템 설정 파일이 저장된 디렉토리                                                                                                                               |
| `/dev`        | 장치 파일(시스템 디바이스)이 저장된 디렉토리                                                                                                                     |
| `/proc`       | 프로세스 정보와 커널 정보가 저장된 가상 디렉토리                                                                                                                 |
| `/sys`        | 시스템 정보 및 장치 관리 정보를 저장한 가상 디렉토리                                                                                                             |
| `/var`        | 가변 데이터(로그, 캐시, 스풀 등)가 저장된 디렉토리                                                                                                               |
| `/tmp`        | 임시 파일이 저장되는 디렉토리                                                                                                                                    |
| `/home`       | 사용자 개인 파일과 설정이 저장된 디렉토리 <br> 일반 사용자들이 로그인시 처음으로 위치하는 디렉토리                                                               |
| `/usr`        | 사용자 프로그램 및 데이터가 저장된 디렉토리                                                                                                                      |
| `/lib`        | 공유 라이브러리 파일이 저장된 디렉토리 <br> 커널 모듈 파일과 프로그램의 실행을 지원해주는 라이브러리를 저장                                                      |
| `/media`      | 이동식 미디어(USB 드라이브 등) 마운트 지점                                                                                                                       |
| `/mnt`        | 수동으로 마운트된 파일 시스템을 위한 디렉토리                                                                                                                    |
| `/opt`        | 추가 소프트웨어 패키지가 저장되는 디렉토리                                                                                                                       |
| `tmp`         | 프로그램(프로세스) 작업시 임시 생성되는 파일을 저장하는 디렉토리<br> 모든 사용자에게 읽기/쓰기를 허용 <br> sticky bit 설정으로 파일소유자만 소유파일을 삭제 가능 |
| `lost+found`  | 결함이 있는 파일에대한 정보를 저장하는 디렉토리                                                                                                                  |
| `/etc/group`  | 그룹의 정보가 담긴 파일                                                                                                                                          |
| `/etc/passwd` | 리소스를 사용 할 수 있는 사용자 목록을저장                                                                                                                       |
| `etc/shadow`  | /etc/passwd의 두번째 필드인 패스워드를 암호화하여 관리<br> 패스워드 만기일, 계정 만기일 등 설정                                                                  |
