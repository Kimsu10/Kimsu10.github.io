드디어 css 부분으로 넘어왔다.  
그동안 나의 백엔드부분을 이쁘게 꾸며주었던 mvp야 고생했다.  
base템플릿에서 mvp부분을 지워주니 다시 못생겨졌다.

![](https://velog.velcdn.com/images/kimsu10/post/8b104e29-3a03-4feb-a832-88a4324c6dc9/image.png)

~~음~ Black & White 터미널인가~~

> [**font-awesome 페이지**](https://cdnjs.com/libraries/font-awesome)

1. 위 cdnjs사이트에 접속하여 최신버전의 font-awesome링크를 복사한다.

![](https://velog.velcdn.com/images/kimsu10/post/7b81a90c-cae8-494e-b355-d72184e768ae/image.png)

2. 기본 pug파일에 mvp를 지운부분에 link를 첨부한다.

```js
link(
  (rel = "stylesheet"),
  (href =
    "https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0/css/all.min.css")
);
```

3. 우선 config폴더를 만들고 \_reset.scss파일을 만들어 아래의 사이트에서 코드를 복붙해준다.

   > [Reset Css 페이지](https://meyerweb.com/eric/tools/css/reset/)

이 코드는 모든 설정을 0으로 돌려준다.  
혹시 변동이 없다면 webpack을 다시 실행해보자.

![](https://velog.velcdn.com/images/kimsu10/post/072bfc41-6d3d-4b37-ac71-d0112429b671/image.png)

으아 어릴적 브라우저가 생각나는 모습으로 나타났다

4. client안에 components와 screens라는 폴더를 만들어준다.  
   components에는 header나 footer같은 템플릿을 넣고, screens에는 home이나 search같은 템플릿을 넣을것이다.

partial이나 mixin에 파일을 만들었다면 scss에도 같은 이름의 파을들을 만들어놔야한다.

![](https://velog.velcdn.com/images/kimsu10/post/74f6242c-9b18-4574-8f46-d94967042a82/image.png)

이제 반복작업을 하면서 내맘대로 꾸미면 된다.
