제어문은 조건식에따라 코드블록을 실행하거나 반복문을 실행할때 사용한다.
코드는 보통 위에서 아래로 실행되는데, 제어문을 사용하면 실행순서를 인위적으로 제어할 수 있다.
하지만 인위적으로 제어시 가독성이 나빠지고 오류가 발생 할 수 있다.

## 1. 블록문

블록문은 자바스크립트에서 하나의 실행단위로 중괄호로 묶인 블록(코드블록)이다.

```js
{
  //블록문
  let a = 1;
}
```

단독으로 쓰이거나 제어문, 함수정의로 사용된다.
블록문은 항상 문의 종료를 의미하기때문에 세미콜론을 붙이지 않는다.

## 2. 조건문(conditional statement)

조건문은 조건식의 평가결과에따라 실행할 코드브록을 결정한다.

```js
if (a % 5 == 0) {
  /*조건식*/ return a;
}
```

조건문에는 if..else문과 switch문의 2가지 조건문이있다.
가독성이 switch문이 더좋은 경우가 아니라면 if..else문을 사용하는것이 좋다.

### 1. if..else 문

if문의 조건식은 참,거짓의 불리언 값으로 평가되어야하며, 만약 불리언이아닌 값으로 평가될경우 자바스크립트 엔진에의해 불리언값으로 강제 변환된다.(암묵적 타입 변환)
if문과 else문은 한번만 사용할 수 있으며, 더 많은 코드블록을 실행하고 싶으면 else if문을 사용하면된다.

```js
if(조건식1){
  코드블록1 //조건식1이 참이면 코드블록1이 실행된다.
}else if(조건식2){
	코드블록2 //조건식 2이 참이면 코드블록2가 실행된다.
}else if(조건식3){
	코드블록3
}...(조건식x){
  	...코드블록x
}else{
	코드블록n //맞는 조건식이 없으면 코드블록n이 실행된다.
}
```

else if문과 else문은 옵션으로 사용하지 않을수 있으며, 코드 블록내에 하나의 문만이 존재한다면 중괄호를 생략할 수 있다.

if..else문은 삼항 조건 연산자로 쓸 수도 있다.

### 1-2. 삼항조건 연산자

```js
//조건문
if (1 + 3 == 2) {
  true;
} else {
  false;
}
//삼항 조건 연산자
let result = 1 + 3 == 2 ? true : false;
```

삼항 연산자는 표현식으로 값처럼 사용할 수 있어 변수에 할당할 수 있다.
반면, if..else문은 문이기때문에 값으로 사용할 수 없어 변수할당이 불가능하다.

### 2. switch 문

switch문은 다양한 상황(case)에따라 실행할 코드블록을 결정한다.
주어진 표현식을 평가하여 일치하는 표현식을가지는 case문으로 실행하고, case문은 상황을 나타내는 표현식을 지정하고 콜론(:)으로 마치고, 뒤에는 실행할 문을 놓는다.
switch문과 일치하는 표현식이 없으면 default문으로 이동한다.(default는 선택사항이다.)

```js
switch (표현식) {
	case 표현식1:
    switch //switch문의 표현식과 표현식1이 일치하면 실행되는 문
      break;
    case 표현식2:
      switch //switch문의 표현식과 표현식2가 일치하면 실행되는 문
      break;
    default:
      switch //switch문의 표현식과 일치하는 case 문이 없을경우 실행되는 문
```

- python은 switch문을 지원하지 않는다.

#### 📚 fall through(폴스루)

switch문에 break를 사용하지않아 switch문이 모든 case문과 default문을 실행할때까지 탈출하지 않게되는 현상을 말한다.
이 경우 case문의 변수들로 값이 계속재할당이 되고 마지막의 default의 변수값으로 재할당되어 원하는 값이나오지 않게된다.
때문에 case문을쓴뒤에는 break를 써야한다.
default문은 마지막 문이기때문에 break를 생략한다.

반면 폴스루를 활용하여 여러 case문을 하나의 조건으로 사용할 수도 있다.

## 3. 반복문 (loop statement)

반복문은 조건식의 평가결과가 참인경우의 코드블록을 실행하고 조건식을 다시평가하여 참인경우의 코드블록을 다시 실행하고 더이상 일치하는 조건식이 없을경우 반복문은 종료된다.
자바스크립트에서는 for 반복문과 while 반복문, do..while 반복문을 제공한다.

### 1. for 반복문

for문은 조건식이 거짓으로 평가될때까지 코드블록을 반복실행한다.

```js
let result = 0;
for (let i = 0; i < 5; i++) {
  result += i;
}
console.log(i); // 10 (1+2+3+4)
```

```js
for( 변수 선언문 | 할당문| 조건식| 증감식) {
  조건식이 참일경우 반복실행된 문
}
```

for 문에는 변수 선언문,조건식,증감식이 들어올 수있는데 어떠한 식도 쓰지않을경우 무한루프한다.
for문에는 for문을 중첩해서 사용할 수 있다.(중첩for문)

```js
for (let i = 0; i < 5; i++) {
  for (let j = 0; j < 5; j++) {
    if (i === j) {
      console.log(`${i}, ${j}`); //'0,0','1,1','2,2','3,3','4,4'
    }
  }
}
```

for문은 반복횟수가 명확할때 사용하고, while문은 반복횟수가 불명확할때 사용한다.

### 2. while 문

while 반복문은 조건식의 평가가 참이면 계속해서 블록을 반복 실행하고, 평가가 거짓이되면 블록을 실행하지 않고 종료한다.
조건식의 평가가 계속 참일경우 무한루프되는데 break문으로 코드블록에서 빠져나올 수 있다.

```js
let i = 0;
while (i < 5) {
  console.log(i);
  i++;
  if (i === 4) break;
}
```

### 3. do..while문

do..while문은 코드블록을 먼저실행하고 조건식을 평가한다. 그래서 코드블록은 무조건 한번 이상 실행된다.

```js
let i = 0;
do {
  console.log(i);
  i++;
} while (i < 5);
// i 가 5보다 작을때까지 코드블록을 반복 실행한다.
```

## 4. break 문

break문을 사용하면 반복문이나 switch문 레이블문의 코드블록을 빠져나올수있다. 이 외의 코드블록에 break문을 입력하면 syntax에러가 발생한다.
break문을 잘 사용하면 불필요한 반복을 피할수 있어 유용하다.

> 📝 레이블 문
> 식별자가 붙은 문으로 프로그램의 실행순서를 제어하는데 사용된다.
> switch문의 case문과 default문도 레이블 문이다.

```js
//식별자
outerSwitch: switch (num) {
  case 1:
    str += "One ";
    break;
  case 2:
    innerSwitch: switch (num) {
      case 2:
        str += "Two ";
        break outerSwitch; //outer~ 레이블 블록을 탈출
      case 3:
        str += "Three ";
        break;
    }
    break;
  case 3:
    str += "Three ";
    break;
}

console.log(str);
```

중첩된 for문의 내부에서 break문을 사용하면 내부 for문에서 나와 외부 for문으로 들어간다.
이때 외부 for문을 탈출하려면 레이블 문을 사용해야한다.
위 경우를 제외하고는 레이블 문으로 빠져나가는것을 권장하지 않는다.

## 5. continue 문

continue문은 반복문의 코드블록실행을 현 지점에서 중단하고 반복문의 증감식으로 실행흐름을 이동시킨다.
if문내에서 실행해야할 코드가 길 경우 continue문을 사용하면 가독성이 좋아진다.

```js
for (let i = 0; i < 10; i++) {
  if (i % 2 === 0) {
    continue;
  }
  console.log(`The number ${i} is odd.`);

  if (i === 7) {
    console.log("The loop is going to end soon.");
  }
}

console.log("The loop has ended.");
```
